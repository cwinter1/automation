        5. Custom columns

          6. Raw data — select columns, flag cells, assign rows

          Check 4–6 source columns to expose to end users. Click a cell in an exposed column to flag it editable and set its dropdown options (comma-separated) — leave blank to unflag. Use a row's Assign dropdown to give that single row to an end user, or tick multiple rows on the left and use "Share selected rows with" to assign them all at once. "Add blank row" inserts a new row with no source data, assignable and flaggable like any other.
